# R1346 Claim-Path Outreach Readiness Report

Release: `FR-NAV1.30.46-HF3.13.28`

This pass implements the owner-observed claim/account defects without redesigning unrelated Franklin functionality.

Implemented product changes:

- Step 3 is a dedicated vertical verification form. The website field and authorization textarea use the available width, the textarea is multi-line and comfortably sized, and the confirmation checkbox has its own row.
- “Continue with this profile” immediately changes to a connecting state, blocks duplicate clicks, reports errors locally, and after success replaces the old state and scrolls/focuses the verification task.
- Password-reset request now visibly loads and replaces the old request form with a privacy-safe “Check your email” confirmation.
- Password-reset completion now clears and removes the password form, removes the reset token from the visible URL, confirms the user is signed in, and gives one primary exact-profile continuation action.
- The password minimum is 8 characters in registration, reset UI, reset runtime validation and password hashing. No uppercase/number/symbol composition rule was added.
- Claim/manage is the strongest ownership action on claimable profiles; Official website remains available as a secondary action.
- Profile Access explicitly refers to the public Franklin Navigator profile.
- The four steps now carry completed/current/future states with `aria-current=step`; the current step is not communicated by color alone.
- The exact selected profile is shown with type/location context. “Wrong profile? Choose another” keeps profile changing available but secondary.
- After profile connection, the task reads “Verify that you manage [profile name].”
- Community Membership remains optional and is not promoted during the pre-submission access task. Payment does not create authority.
- The management-area factual-correction action is labeled “Correct factual listing details” to distinguish it from the general review/correction path without removing either free route.
- `/api/accounts/me` now returns representation-review state/revision/timestamp needed for a real Pending status after submission.
- The durable “NO SILENT CLICKS” rule is qualification-gated.

Qualification includes a controlled, non-production headless-browser fixture with an exact Franklin Navigator profile path, password recovery, connection, Step 3 desktop/mobile geometry, keyboard order, access-request submission, Pending state, no checkout call, no pre-VERIFIED Profile Center link, and free correction availability. Screenshots and its machine-readable result are generated by the exact-head workflow outside the deterministic source ZIP.
