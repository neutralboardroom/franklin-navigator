# R1342 Support Page UX / Regression Report

- ACCOUNT_ACCESS query routing selects Account Access immediately.
- Account-access support is visually prioritized.
- **← Back to sign in** is present and keeps exact profile context when supplied.
- **Reset password** routes to self-service recovery.
- Support form is one logical field per row with consistent responsive spacing.
- Existing support submission confirmation and sensitive-data warning remain.
- Email and phone support remain.
- Profile-access, corrections/removal, membership/billing, accessibility, and other support categories remain.
- Unsigned visitors see **Community Membership for new memberships — $35/year**; actual membership state is still resolved only after authentication.
